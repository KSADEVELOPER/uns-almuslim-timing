# توقيت آيات التلاوات في أنس المسلم

هنا توقيت بداية ونهاية كل آية داخل ملفّات تلاوة السور الكاملة، لعددٍ من القرّاء
برواية حفص عن عاصم. الغرض منه أن يتتبّع تطبيق «أنس المسلم» التلاوة آيةً بآية، فيُظلّل
الآية التي تُتلى ويمرّر إليها مع الصوت.

هذا توقيت فقط، وليس صوتًا. ملفّات الصوت تبقى عند مصادرها، وما هنا جدولٌ يقول: الآية
الأولى من كذا إلى كذا، والثانية من كذا إلى كذا، بالمللي ثانية.

## كيف وُلّد

لكل قارئ نُزّلت تلاوته سورةً سورة، ثمّ حوذي صوتها على نصّ الآيات بمحاذاةٍ صوتيّة
محلّيّة، فنتج زمن كل آية. ثمّ فُحص كل ملفّ آيةً آية للتأكّد من سلامته.

## البنية

```
manifest.json
timing/<رقم القارئ>/<رقم السورة>.json
```

رقم السورة من ثلاث خانات، مثل `001.json` للفاتحة و`114.json` للناس.

كل ملفّ سورة بهذا الشكل:

```json
{
  "reader_index": 11,
  "surah": 1,
  "timing": [
    { "ayah": 1, "start_time": 0, "end_time": 7880 },
    { "ayah": 2, "start_time": 7880, "end_time": 13040 }
  ]
}
```

الزمن بالمللي ثانية من بداية ملفّ السورة.

## الوصول المباشر

كل ملفّ متاحٌ برابطٍ مباشر بهذا النمط:

```
https://raw.githubusercontent.com/KSADEVELOPER/uns-almuslim-timing/main/timing/<القارئ>/<السورة>.json
```

## حقول manifest

لكل قارئ:

- `index` رقمه في قائمة قرّاء التطبيق.
- `name` اسمه.
- `surahs` أرقام السور المتوفّر لها توقيت.
- `unavailable` سورٌ لا صوت لها عند المصدر أصلًا.
- `flagged` سورٌ محاذاتها غير دقيقة في بعض آياتها، يُنصح بعرضها استماعًا كاملًا لا آيةً بآية.
